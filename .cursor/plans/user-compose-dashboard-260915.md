## 이 Plan이 끝나면 사용자가 얻는 것

평소 파일은 지금처럼 바탕화면·다운로드에 그냥 둠. DocuDog은 뒤에서 분류함.

추가로 할 수 있는 일:

1. 트레이에서 **현황 페이지**를 연다. 오늘 몇 건인지, 민감한 파일 제목이 뭔지, 개가 살아 있는지 본다. Cursor를 안 켜도 됨.
2. 그 페이지(또는 나중엔 체크박스)에서 관련 파일 몇 개를 고르고, **“임원용 한 장”** 이라고 적으면 **새 파일**이 생긴다. 원본은 그대로다.
3. 같은 방식으로 **후임용 인수인계 한 장**(개요 + 읽는 순서 + 문서 목록)을 만들어 메일로 보낸다.

에이전트(Cursor/Claude)로 묻기는 **그대로 MCP가 주 입구**. 이 Plan은 MCP를 대체하지 않음.

---

## 사용자를 둘로 나누지 않고, 장면으로 나눔

같은 사람이라도 쓰는 손이 다름. 화면을 두 개 제품으로 쪼개지 않음.

| 장면 | 누가 | 무엇을 염 | 무엇을 얻음 |
|------|------|-----------|-------------|
| A. 돌아보기 | Word/한글만 쓰는 날 | 트레이 → 현황 | 살아 있나, 오늘, P1 제목 |
| B. 물어보기 | Cursor를 켠 날 | 채팅 + MCP | 최신 견적, 이 과제 파일들 |
| C. 만들어서 주기 | 주간보고·인수인계 날 | 현황에서 고르기 → 저장 | 메일/공유할 MD(나중 HTML) |

장면 B는 이미 거의 있음. 이 Plan은 **A를 보이게 하고, C를 손으로 가능하게** 함.

## 사용자가 여는 곳 (이것만 기억)

```
[트레이 아이콘]
    ├─ Open status page     ← 사람이 보는 현황 (이 Plan)
    ├─ Open data folder     ← 고급. 평소 안 열어도 됨
    ├─ Pause / MCP 연결 …  ← 기존
    └─ (개는 계속 뒤에서 분류)

결과 파일 위치 (사용자가 찾는 곳):
    %USERPROFILE%/.docudog/composed/   ← “만든 보고서·인수인계”
    원본 Word/HWP/PDF                   ← 안 옮김
```

시작하자마자 브라우저가 뜨면 안 됨. **메뉴를 눌렀을 때만** 현황이 열림.

## 하루·한 달 사용 (목표 상태)

### 평범한 화요일

1. 사용자는 엑셀·한글을 저장함. 아무것도 안 함.
2. PC가 잠깐 비면 분류됨. P1이면 토스트가 한 번 뜸. (기존)
3. “아까 그거 민감했나?” 싶으면 트레이 → **Open status page**. 민감 구간에 파일 이름과 경로만 보임. 본문은 안 보임.

### 목요일 주간보고 (장면 C)

1. 현황에서 **최근 대화** 또는 **최근 분류** 목록이 보임.
2. `견적_최종.pptx`, `단가.xlsx`, `메일요청.pdf` 에 체크. `_초안`은 빼거나, 페이지가 “이전 버전”으로 접어 줌.
3. 칸에 `임원용 10줄, 일정만 표` 라고 적고 **만들기**.
4. `composed/` 에 MD가 생김. 탐색기로 그 폴더를 열어 메일에 첨부. (HTML이 생기면 브라우저에서 복사해도 됨)

### 후임이 오는 달 (장면 C, 인수인계)

1. 같은 화면에서 그 과제 스레드를 고르거나 파일을 직접 체크.
2. 종류를 **인수인계**로 고름. (자유 문장 요약이 아님)
3. 나온 파일을 후임에게 줌. 후임은 **개요 → 이 순서대로 읽어 → 표의 경로**만 따라감. DocuDog 설치가 없어도 파일을 읽을 수 있음.

### Cursor를 켠 날 (장면 B, 기존 유지)

“Q3 견적 최신 뭐야”는 채팅. 현황 페이지를 안 열어도 됨.

## 단계별 구현 (사용자 능력 = 완료 조건)

한 단계가 끝나야 다음 단계의 손을 넣음. 엔지니어 작업은 각 단계 아래에 짧게만 적음.

### 단계 0 — “현황을 찾을 수 있다” (`260915-03` 앞부분)

**사용자가 할 수 있음**

- `--tray`로 켠 뒤 메뉴 **Open status page**를 누른다.
- 브라우저에 오늘 건수, 할 일, 최근 대화가 보인다. (지금 이미 만들어지는 `DocuDog_status.html`)
- 시작 시에는 브라우저가 안 뜬다.

**아직 못 함:** 새로고침해도 파일이 오래됐으면 옛날 숫자. 체크박스로 보고서 만들기. 일시정지 버튼.

**구현 힌트:** `tray_app.py`에 항목 추가, `webbrowser.open`으로 status HTML. Features에 “트레이에서 연다” 한 줄.

**사용 테스트:** Word만 쓰는 사람에게 아이콘만 알려 주고, 도움말 없이 오늘 숫자를 읽게 함.

**사용자가 할 수 있음**

- 현황 **맨 위 3줄**만 봐도 됨: 실행 중인지 / 마지막 분류 시각 / 모델이 mock이면 “연습 모드”처럼 보임.

### 단계 2 — “고르고, 한 장 받는다” (`260915-01` 엔진 + 현황에서 만들기)

사용자 손 기준으로 **CLI를 주 입구로 두지 않음.** CLI는 엔진·테스트용. 사람이 만지는 것은 현황 페이지.

**사용자가 할 수 있음**

1. 현황에서 **이미 분류된** 최근 파일(또는 한 스레드의 멤버)에 체크. 최대 개수 초과면 “너무 많음, 8개까지” 같은 말이 보임.
2. 종류: **요약·보고서**. 요청 문장 예: `임원용 한 장`.
3. **만들기** → 끝나면 “파일 위치”와 **폴더 열기**.
4. 연 파일에 보임: 언제 만들었는지, 어떤 원본을 썼는지, 본문, “원본을 대체하지 않음”.
5. 민감(P1) 파일은 제목·경로만 들어가고, 본문은 안 섞임. 화면에 “민감은 내용 없이 목록만”이 보임.

**아직 못 함:** 워드(.docx)로 저장. 미분류 파일을 이 자리에서 바로 분류. 폴더 트리에서 아무 파일이나 탐색.

**구현 힌트:** `docudog/compose.py` 엔진 + `composed/` (워치 밖). 1차는 MD. 페이지는 단계 0 HTML에 폼을 붙이거나, 이 단계에서 loopback(`127.0.0.1`만) 한 페이지로 올려 **만들기 POST**를 받음. 외부 망에 안 염. MCP 포트와 분리. 에이전트용으로는 `compose_preview`(문자열만) 선택. 디스크 저장의 주 손은 로컬 페이지.

**사용 테스트:** 포맷이 다른 문서 3개(예: docx, pdf, pptx 또는 hwp)를 고르고, 메일에 넣을 MD가 생김. 바탕화면 원본 이름·위치 불변. P1 픽스처를 섞으면 그 파일 내용이 결과에 없음.

단계 0만 있고 만들기가 없으면 사용자는 현황만 보다가 그만둠. **단계 2가 이 에픽의 첫 체감 기능.** 단계 0·1은 짧게 끝냄.

---

### 단계 3 — “후임에게 지도를 준다” (`260915-02`)

**사용자가 할 수 있음**

- 만들기 종류에 **인수인계 / OJT** 가 있음.
- 나온 파일 구조가 매번 같음:
  1. 개요 — 무슨 일인지, 지금 볼 파일 1~2개
  2. 읽는 순서 — 왜 그 다음인지 한 줄씩
  3. 문서 목록 표 — 이름, 경로, 형식, 민감 여부, 한 줄 설명
  4. 비어 있는 것 — 못 읽은 PDF, 아직 없는 주기 문서
- `_초안`이 최신 행을 가리지 않음. 이전 버전은 아래 또는 접힘.
- 후임은 DocuDog 없이 이 파일만 받음.

**아직 못 함:** 후임 PC에 개 데이터 통째 복사. 폴더 전체 자동 덤프.

**사용 테스트:** 만든 사람을 옆에 안 두고, 다른 사람이 표의 경로만 따라가 첫 파일을 염.

---

### 단계 4 — “브라우저·메일에서 보기 좋다”

**사용자가 할 수 있음**

- 만들기 후 MD와 **같은 이름의 HTML**이 생김. 현황과 같은 방식.
- HTML 목록에서 경로를 눌러 원본을 열 수 있으면 더 좋음 (안 되면 경로 복사라도).

**아직 못 함:** 회사 양식 그대로인 워드, 한글(.hwp) 생성.

**사용 테스트:** HTML을 메일에 “복사해서 붙여넣기” 또는 첨부 후 상대가 브라우저로 읽음.

---

### 단계 5 — “워드 파일로 주세요” (얇게만)

**사용자가 할 수 있음**

- 만들기 옵션에 **Word(.docx)** — 제목과 문단만. 예쁜 템플릿 아님.
- 한글이 깨지면 HTML을 한글에서 열라고 화면에 안내.

**보류:** HWP 생성, PDF 조판, 자동 메일 발송.

---

### 단계 6 — “페이지에서 잠깐 멈춘다” (있으면 좋음)

**사용자가 할 수 있음**

- 현황에서 **일시정지 / 재개** (트레이와 같은 동작).
- 새로고침하면 숫자가 지금과 맞음 (loopback 서버가 있을 때).

단계 2에서 이미 loopback을 썼으면 여기 공수는 작음. 안 썼으면 이 단계에서 서버를 붙임.

**사용 테스트:** 회의 전에 페이지에서 멈추고, 트레이 메뉴와 상태가 같음.

## 권장 일정 감각 (우선순위)

사용자 체감 순:

1. 단계 0 (현황 열기) — 반나절 급  
2. 단계 2 (고르고 MD 받기) — 이 에픽의 본편  
3. 단계 3 (인수인계 뼈대) — 본편과 같은 엔진, 템플릿만  
4. 단계 1은 0과 같이 하거나 2 전에 끼움  
5. 단계 4 HTML → 5 DOCX → 6 일시정지

`260910-02`(최신본 표시)가 있으면 목록에서 `_최종`을 고르기 쉬움. **없어도 단계 2는 시작 가능.** 없으면 사용자가 체크를 직접 가리면 됨.
