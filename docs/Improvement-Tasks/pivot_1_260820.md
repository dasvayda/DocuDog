# Project DocuDog: Cursor Development Context & Spec Prompt

## 1. System Identity & Core Philosophy

DocuDog은 PC 및 Edge Device(온디바이스 AI, NPU 탑재 PC, 사내 로컬 서버) 전반에서 백신(Antivirus)처럼 상시 백그라운드 구동되는 "Zero-Touch Local AI Engine"임.

- Core Message: "정리하지 말고 저장만 하라. 찾지 말고 AI에게 물어보라."

- Anti-Pattern: 정리를 위해 사용자의 입력을 강제하거나(No-Manual-Tagging), 파일 위치/이름을 변경하지 않음. 사용자의 작업 환경에 개입하는 독립 GUI 앱([status.md](http://status.md) 열기 등)을 전면에 내세우지 않음.

- Native Cross-Device Strategy: Windows/Mac 로컬 PC부터 폐쇄망 Edge 디바이스, NPU 노트북까지 동일한 표준 Protocol(MCP) 및 Local Inference Engine으로 동작함.

---

## 2. Target User & Persona

- Primary Target: Obsidian/Notion을 쓰거나 도입하려 했으나, 매번 노트를 정리하고 링크/태그를 거는 수동 노동(Organizer Fatigue)에 지쳐 중도 포기한 지식 노동자, 엔지니어, 기획자.

- Key UX Goal: 사용자 관점에서는 파일이 바탕화면이나 다운로드 폴더, 공유 폴더에 `_v1`, `_최종_진짜.docx` 형태로 개판으로 쌓여도, AI 코파일럿(Cursor, Claude Desktop) 채팅창에서 자연어로 질의하면 최신 맥락을 정확히 찾아주는 경험을 제공함.

## 3. Architecture & Core Concept Modules

### A. Background Edge Execution & Silent Guard (백신형 상시 구동)

- Tray Engine: System Tray 앱 형태로 부팅 시 백그라운드 상시 구동.

- Resource Guard: `psutil.LOW_PRIORITY_CLASS` 적용. 사용자 키보드/마우스 입력 중지(Idle Time) 시 및 AC 전원 연결 시에만 추론(Inference) 실행. 백그라운드 메모리 점유 최소화.

- System Isolation: 모든 기계용 상태 파일, 로그, 인덱스 메타데이터는 사용자 폴더를 더럽히지 않고 `.docudog/` (숨김 서브디렉터리) 내부로 격리 처리.

- OS Native Notification: P1(대외비) 보안 문서 발견 등 치명적 이벤트 발생 시에만 윈도우 토스트 알림으로 1초 노출 후 소멸.

### B. Deep Content Extraction & Parsing Engine (무중단 멀티 포맷)

- Full-Text Extractor: `.txt`, `.md`, `.docx`, `.pptx`, `.xlsx`, `.hwp`, `.hwpx`, `.pdf` (PyPDF/pdfplumber 기반 경량 추출) 본문 파싱 내장.

- Binary Document Support: 오피스 및 이진(Binary) 문서를 백그라운드 유휴 시간에 자동으로 마크다운/JSON 메타 데이터화.

### C. Context Building & Lineage Tracking (업무 맥락 및 버전 묶음)

- Stable File ID: 파일명이나 위치가 변경되어도 본문 및 고유 특성 기반으로 동일 문서 추적.

- Semantic Lineage & Shadow Git: `_v1`, `_최종` 등 파편화된 문서의 변경 이력을 AI가 비교하여 한 줄 변경 요약(Semantic Diff) 생성 (예: "v1.0 -> v1.1: 마케팅 예산 500만 원 증액").

- Context Bundle: 파일 생성 시간대(Temporal Window) 및 인접성 패턴을 감지해 참고 엑셀, 이미지, 보고서를 하나의 '업무 과제 묶음'으로 인덱싱.

### D. Zero-Friction MCP Integration (1-Click AI Interface)

- Protocol: JSON-RPC 2.0 기반 `stdio` 및 `Localhost SSE` ([http://localhost:8765/sse](http://localhost:8765/sse)) 타겟 지원. PC 및 Edge Device 자원 소모 최소화.

- Auto-Installer / Configuration Injection: Node.js/npm 설치 요구 절대 금지. 클릭 한 번으로 `claude_desktop_config.json` 및 Cursor MCP 설정을 자동 감지 및 주입하는 GUI/스크립트 제공.

- Exposed MCP Tools:

  * `docudog_search`: 의미(Semantic) + 시간대 + P등급 기준 맥락 검색

  * `docudog_get_lineage`: 파편화된 문서 중 최신 진화 노드(Final Version) 및 차이점 반환

  * `docudog_get_context_bundle`: 특정 문서와 연관된 참고 자료 메타데이터 묶음 추출

### E. Privacy & Edge Audit Guard (보안 및 차단)

- Zero-Trust MCP Guard: 외부 클라우드 LLM(Claude 등)으로 프롬프트가 나갈 때, P1(대외비)/주민번호 등 민감 문서의 원본 전송을 MCP 레이어에서 물리적 차단 (메타 요약만 허용).

- Local-Only Processing: 모든 문서 파싱, 백링크 및 계보 구성, 보안 등급(P1~P4) 판별은 에지 디바이스 내부(LiteRT, LM Studio, Ollama 등)에서만 수행.

## 4. Key Priorities for Cursor Execution

1. Clean Up User Space: Root 디렉터리의 모든 시스템 로그/상태값`state.json`, `activity.log` 등)을 `.docudog/` 숨김 서브디렉터리로 정리하고 `status.md` 열람 강제 UX 제거.

2. Build 1-Click MCP Auto-Configurator: 사용자가 CLI 조작 없이 트레이 앱 버튼 하나로 Cursor/Claude MCP JSON을 갱신하는 런처 구현.

3. Complete PDF & Office Extractor: 스킵되던 PDF 파싱 지원을 신속히 내장하여 오피스 파이프라인 완결성 확보.

4. Enhance Semantic Diff & Lineage Engine: `lineage.py` 고도화를 통해 파일명이 다른 두 문서 간의 '한 줄 변경 요약' 출력 기능 완성.
